# Social Samurai — promo site

Marketing and purchase site for Social Samurai, a live game night for work
teams: one big screen, every phone a controller, a sensei runs seven rounds.

Static site, no build step. Open `index.html` or serve with
`python3 -m http.server 8000`.

- Landing page: `index.html`
- Legal: `privacy.html`, `terms.html` (drafts)
- Plan (domain, billing, legal, launch): `docs/PLAN.md`
